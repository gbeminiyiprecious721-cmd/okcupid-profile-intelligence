# Planning and reports

Design documents (`01` to `04`) and one report per phase of the application build, with the measurement files each report quotes.

| Item | What it holds |
|---|---|
| `01_architecture.md`, `02_ux_and_design_system.md`, `03_synthetic_profiles.md`, `04_implementation_plan.md` | the design and the plan |
| `phase4` to `phase7` reports and `phase7_*.json` | test, export, performance and security audit records |
| `phase9`, `phase9b`, `phase9c` | the visual redesign, with before and after performance figures |
| `phase10a`, `phase10b` | the final review and the repository audit |
| `final_screenshots/` | twelve screenshots of the finished application: home, Discovery and the Lab, on desktop and phone |

The reports mention before and after screenshot folders and comparison pages. Those images (about 190 MB) are kept on the developer's computer only and are not part of the repository. The phase 7 exposure audit record was overwritten by a later run, and its note says so.
